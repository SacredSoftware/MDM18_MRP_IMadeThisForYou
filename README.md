This repository contains the critical codebase and associated files used to run my immersive installation I Made This For You. 

All elements of this repository were developed for Toronto Metropolitan University as part of my thesis Major Research Project.

This project was developed to run on two machines simultaneously. The repository has been organized to showcase which files operated on each machine. 

The repository contains: 
  
  -->The directories and associated files located on gallery machine - responsible for generating enivornment visuals and music
  
  -->The directories and associated files located on my portable mac machine - repsonsible for generating the algorithmic mirror visual at the centre of the installation
 
  -->Both directories are largely duplicates, though certain files have been optimized for each machine's role

Notes: 
  
  -This repository does not contain the corresponding files for supporting libraries (pyktok, yt-dlp, Playwright, Electron). These libraries must be added for files to run properly. 

  -Scripts have been developed using Claude as a co-pilot.
